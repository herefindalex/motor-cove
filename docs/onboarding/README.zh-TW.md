# 貢獻者入門

[English](README.md) · [简体中文](README.zh-CN.md)

此頁面可協助每個工程角色找到安全的首要任務、可能更改的合約以及最小的有意義的驗證。從[貢獻](../../CONTRIBUTING.zh-TW.md) 和[專案範圍](../project-scope.zh-TW.md) 開始。

## 前端

1. 將市場路由從 `apps/web/src/app/App.tsx` 追蹤到特徵公共索引。
2. 將隔離的 UI 狀態新增至 Storybook 故事中，而無需將 SDK 匯入功能/模型程式碼。
3. 執行 Web 類型檢查、Storybook 建置、架構檢查和相關瀏覽器場景。

共享合約：API Zod 模式、鏈 ABI、部署設定、交易日誌模式。

## 協定

1. 一起閱讀 `IMotorCoveEscrow.sol`、實作、單元測試和不變處理程序。
2. 在更改轉換或資產轉移之前新增錯誤路徑測試。
3. 重新產生 ABI 工件並列出受影響的前端、解碼器、投影器和文件使用者。

共享合約：ABI、事件、自訂錯誤、清單協定版本。

## API 和後端

1. 透過路由、用例、閱讀器連接埠、演示者和 Zod 模式追蹤 `/v1/sales/{saleId}`。
2. 在變更傳輸資料結構之前新增回應欄位測試。
3. 僅保留 API 讀取器，切勿匯入投影寫入器或維護匯出。

共享合約：API 模式/OpenAPI 和資料庫讀取器 DTO。

## Indexer

1. 追蹤來自 Viem 的事件，透過純投影器解碼到 SQLite 適配器中。
2. 新增針對無效排序的純投影器測試或具有受控邊界的攝取測試。
3. 保留順序、來源身分、原子檢查點行為以及偵測和停止語義。

共享合約：ABI 事件、投影器版本、日誌範圍、資料庫投影 writer。

## 資料庫和操作

1. 運行四個臨時資料庫套件；不要將練習指向現有工作區資料庫。
2. 更改 Drizzle 架構並產生經過審核的正向遷移加架構合約。
3. 測試全新安裝、歷史篡改、約束、鎖定、標記和恢復邊界。

共享合約：SQL 歷史記錄、模式合約、套件匯出、環境佈局、根命令。

## 品質保證和交付

1. 將場景 ID 對應到其來源、測試選擇器、環境等級和限制。
2. 增加一個負固定裝置來證明新的檢查器規則可能會失敗。
3. 將本地、真實的 SQLite、真實的 Anvil、瀏覽器自動化和手動錢包證據分開。

繼續[更改配方](change-recipes.zh-TW.md)、[場景目錄](../testing/scenario-catalog.zh-TW.md)和[所有權](../collaboration/ownership-and-contracts.zh-TW.md)。
