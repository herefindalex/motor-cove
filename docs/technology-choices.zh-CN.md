# 技术选择

[English](technology-choices.md) · [繁體中文](technology-choices.zh-TW.md)

此页面回答了检查的工作区使用哪些工具、为什么每个工具都有有限的角色，以及安装中未暗示哪些声明。确切的版本来自清单、锁定文件、Foundry 配置和[工具链](toolchain.zh-CN.md) 中的本地工具输出。

| 技术                                     | 实际角色及进入                             | 为什么在这里                             | 边界与权衡                                           |
| ---------------------------------------- | ------------------------------------------ | ---------------------------------------- | ---------------------------------------------------- |
| React 19 + Vite 8 + TypeScript 5.9       | Web 运行时并在 `apps/web` 下构建           | 具有快速本地构建的小型浏览器界面         | 不拥有钱包或服务器状态；当前的浏览器支持没有单独认证 |
| Wagmi 3 + Viem 2                         | 注入连接器和鞋底 TypeScript EVM 客户端     | 类型为 RPC、ABI 读/写、收据和日志        | 无托管钱包套件、SIWE 或公共网络最终声明              |
| TanStack Query 5                         | API Web 组合中的查询缓存                   | 将服务器快照保留在钱包和表单状态之外     | 新的查询并不能证明 Indexer 已到达链头                |
| Fastify 5                                | 本地只读 HTTP API                          | 小显作文根与健康路由                     | 不是结算引擎，也不是认证服务                         |
| Zod 4+生成的OpenAPI                      | 浏览器安全的传输数据与部署清单验证         | 生产者和消费者共享运行时验证             | 模式有效性并不建立数据新鲜度或链真实性               |
| SQLite 3.53.4 + better-sqlite3 13        | 本地混合权威来源数据库和同步事务           | 非常适合单主机演示和短原子写入           | 同一主机WAL和一名作家；没有网络文件系统支持          |
| Drizzle ORM 0.45.2 + Drizzle Kit 0.31.10 | `packages/database` 中的架构和本机迁移工件 | 有序 SQL 历史记录和类型化模式源          | 套件不会取代项目所有权、锁定或验证防护               |
| Solidity 0.8.24 + Foundry/Anvil 1.8.3    | 合约、模糊/不变测试、本地链                | 具有受控时间的确定性局部 EVM 循环        | Anvil 不是公网运行的证据                             |
| OpenZeppelin 5.6.1                       | ERC-721、所有权和可重入原语                | 避免自定义令牌/安全原语                  | 集成仍然需要 MotorCove 特定的不变量和测试            |
| Vitest 5 + React 测试库 16               | 单元和 JSDOM 组件测试                      | 将纯规则与呈现的组件状态检查分开         | JSDOM 不是注入钱包或布局引擎的证据                   |
| Playwright 1.63                          | 针对隔离的本地堆栈的浏览器 E2E             | 涵盖可见的交易和恢复流程                 | 自动化 EIP-1193 适配器不是手动钱包测试               |
| Storybook 10                             | 隔离的 UI 状态开发                         | 显示受控组件状态                         | 赛程仅供说明，并非连锁证据                           |
| pnpm 12.5.1                              | 固定工作区包管理器                         | 确定性工作区和锁定文件                   | 根脚本仍然是项目命令，而不是 pnpm 内置命令           |
| GitHub Actions                           | 执行远程 CI 工作流程                       | 镜像本地文档烟雾、验证和 E2E 门          | 一次通过的运行并不能证明分支保护或需要审查的设置     |
| TypeScript 架构检查器                    | 导入图表和负片                             | 在没有框架的情况下强制执行选定的依赖方向 | 检查静态导入；运行时隔离仍然取决于组合               |

建议或排除的工具（例如 Postgres、The Graph、SIWE、Kubernetes、ethers 和 RainbowKit）不属于已实现堆栈的一部分。
