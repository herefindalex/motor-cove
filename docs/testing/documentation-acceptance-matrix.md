## Status interpretation

- **Implemented**: the repository contains the required documentation or check.
- **Partially implemented**: some required user path is still blocked by a product
  implementation gap.
- **Partially verified**: local evidence exists, while remote or manual enforcement
  has not been observed.
- **Limited**: the repository intentionally has no evidence of that kind and says so.
  authorized work and verification finish.
