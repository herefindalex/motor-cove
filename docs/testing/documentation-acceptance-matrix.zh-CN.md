## 状态解读

- **已实施**：存储库包含所需的文档或检查。
- **部分实现**：某些必需的用户路径仍然被产品阻止
  执行差距。
- **部分验证**：本地证据存在，但远程或手动执行
  尚未观察到。
- **有限**：存储库故意没有此类证据并这么说。
  授权工作和验证完成。
