## 狀態解讀

- **已實施**：儲存庫包含所需的文件或檢查。
- **部分實作**：某些必要的使用者路徑仍然被產品阻止
  執行差距。
- **部分驗證**：本地證據存在，但遠端或手動執行
  尚未觀察到。
- **有限**：儲存庫故意沒有此類證據並這麼說。
  授權工作和驗證完成。
