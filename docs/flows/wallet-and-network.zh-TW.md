# 錢包和網路流量

[English](wallet-and-network.md) · [简体中文](wallet-and-network.zh-CN.md)

此頁面追蹤連接、鏈驗證、拒絕和交易上下文保存。

## 權威來源及連接器方式

在正常操作中，用户控制注入的 EIP-1193 钱包。連接將帳戶和鏈公開給 Web 應用程式；它不是登入、後端身份驗證或金鑰保管。

本地演示可以明確設定 `VITE_MOTORCOVE_DEMO_WALLET=1`。然后，前端添加两个由解锁的 Anvil 卖家和买家地址支持的 Wagmi 模拟连接器。此模式仅限于 Vite 开发服务器和环回 RPC。它嵌入公共測試地址，而不是私鑰。连接器仍然向 Anvil 提交真实的 JSON-RPC 交易。

## 流量

1. `WagmiProvider` 公開注入的連接器，並在明確啟用時公開本地演示
   `apps/web/src/app/composition.tsx` 連接器。
2. 當瀏覽器沒有提供程式時，錢包整合會過濾掉注入的連接器。的
   功能呈現可操作的不可用狀態，而不是死連線按鈕。
3. 用戶選擇連接器。連線錯誤在重試控制項旁邊仍然可見。
4. 此功能衍生出斷開連接、錯誤網路和連接狀態。
5. 一项功能要求其 EVM 端口模拟针对当前部署的合约调用。
6. 錢包可能會拒絕、切換鍊或提交。持久意圖是在請求之前記錄的。
7. 交易觀察者遵循一個已知的哈希值，獨立於以後的帳戶或鏈的變化。

## 失敗與恢復

在打开钱包请求之前，网关会保存待处理的意图，并通过公共 RPC 和钱包提供商验证预期的部署。它將公共鏈 ID、錢包客戶端鏈 ID 和每個提供者的託管 `deploymentId()` 與不可變的意圖進行比較。此檢查還涵蓋代幣批准。不匹配或不可用的證明在錢包寫入並記錄 `FAILED_BEFORE_SUBMIT / OPERATION_ENVIRONMENT_MISMATCH` 之前停止。後來的錢包結果仍然遵循正常的哈希和未知結果恢復規則。

拒絕可以安全地作為新的用戶決定重試。未知的提交結果則不然。帳戶或鏈的變更不得刪除先前操作儲存的不可變帳戶、鏈、合約、操作、隨機數或雜湊值。重新加載僅恢復具有足夠證據以進行查詢而無需提交的條目。

自動瀏覽器覆蓋範圍有兩個不同的範圍：本機示範連接器證明正常的環回交易路徑，而受控的 EIP-1193 提供者則注入拒絕、傳輸遺失、帳戶變更和網路變更。也没有证据表明 MetaMask 或其他浏览器扩展是手动执行的。

證據：`TX-001`，`TX-002`；源位於 `capabilities/wallet`、`capabilities/transactions` 和 `integrations/evm` 下。下一頁：[交易生命週期](../protocol/transaction-lifecycle.zh-TW.md)。

## 證據同一性和持久性失敗

如果錢包返回哈希，但日誌無法持久保存提交的狀態，則 UI 將操作上下文保留在記憶體中，顯示可複製哈希並顯示非持久性警告，並在當前標籤中繼續只讀觀察。在此狀態下，重新載入恢復受到明確限制。未能堅持初始意圖仍會在任何錢包請求之前停止。

反映的投影結果與觀察到的交易哈希、區塊哈希、日誌索引、部署和投影建置綁定。在不同的區塊或日誌中重新包含相同的交易會使 API 查找之前的當前反射無效。 API 中斷可能會保留相同身分的歷史證據，但不能提升先前身分的證據。
