# 實施和文件計劃

[English](implementation-plan.md) · [简体中文](implementation-plan.zh-CN.md)

此頁面對齊原始 P0–P5、資料庫 D0–D5 和文件 DOC-P0–DOC-P5 工作，而無需建立競爭路線圖。檢查項目已檢查實施情況和現有證據。剩餘限制以擁有它們的項目命名。

## 產品 P0–P5

- [x] **P0:** 工作空間、嚴格的 TypeScript 邊界、架構圖和負夾具。
- [x] **P1:** ERC-721 託管上市/融資/結算、拉取索賠、退款、撤回和回收。
- [x] **P2：** 本機部署、事件擷取、託管 SQLite 投影、唯讀 API 和
      出處。
- [x] **P3：** 前端特性/能力/適配器實作與持久事務觀察。
- [x] **P4：** 追趕、重播、重建、重新索引、替換/重組恢復、重置、備份追趕、
      和錨定銷售/代幣對帳。本地製程和受控SQLite故障案例通過；
      硬體斷電和公共網路歷史記錄仍不屬於當地證據。
- [x] **P5：** 本地和遠端 CI 門、所有權、協作文件、演示和證據。
      遠程 CI 證據是特定於提交的。分支機構保護、最終審閱者身分以及
      手動錢包證據仍然由所有者控制檢查。

## 資料庫 D0–D5

- [x] **D0:** 現有資料庫/歷史記錄檢查為唯讀；非收養環境邊界
      記錄了。
- [x] **D1：** 一個資料庫包、架構、編解碼器、託管路徑、角色匯出、鎖和標記。
- [x] **D2：** 本機遷移歷史記錄、來源摘要、運行時檢查、注入的 SQL 回滾和
      故障標記恢復已通過。真正的`0000`到`0001`保留資料升級夾具
      涵蓋 DB-03 以取得儲存庫的當前歷史記錄。
- [x] **D3:** 目錄種子、持久性鏈步日誌、已知雜湊恢復、種子版本衝突以及
      已完成引導程式重複使用已通過。廣播到哈希視窗中真正的進程終止仍然是
      規定的作業系統故障注入間隙。
- [x] **D4：** 備份/復原、重建/重新索引、重組證據保留、頭後復原追趕、
      對帳，一次快照讀取，並重置本地通過的部署不匹配檢測。
- [x] **D5：** 指令、運作手冊、本機全端演練、重設拒絕矩陣與平行套件
      隔離過去了。 DB-01–DB-54 矩陣保留硬體層級和外部環境
      限制。

## 文件 DOC-P0–DOC-P5

- [x] **DOC-P0：** 儲存庫、腳本、測試、鎖定檔案、CI 和現有文件。
- [x] **DOC-P1：** 雙語入口點、範圍、狀態、能力/證據圖和導航。
- [x] **DOC-P2：** 架構、依賴規則、資料權威來源、協定、事務和
      提供者-消費者文件。
- [x] **DOC-P3：** 入門、所有權、並行開發和更改方法。
- [x] **DOC-P4：** 測試策略、場景矩陣、演示、運行手冊、CI 門和證據記錄。
- [x] **DOC-P5：** 連結、名稱、命令、產生漂移、雙語奇偶校驗和虛假證據檢查；
      DOC-01–DOC-32 在驗收矩陣中進行追蹤。
