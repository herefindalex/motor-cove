# 实施和文件计划

[English](implementation-plan.md) · [繁體中文](implementation-plan.zh-TW.md)

此页面对齐原始 P0–P5、数据库 D0–D5 和文档 DOC-P0–DOC-P5 工作，而无需创建竞争路线图。检查项目已检查实施情况和现有证据。剩余限制以拥有它们的项目命名。

## 产品 P0–P5

- [x] **P0:** 工作空间、严格的 TypeScript 边界、架构图和负夹具。
- [x] **P1:** ERC-721 托管上市/融资/结算、拉取索赔、退款、撤回和回收。
- [x] **P2：** 本地部署、事件摄取、托管 SQLite 投影、只读 API 和
      出处。
- [x] **P3：** 前端特性/能力/适配器实现和持久事务观察。
- [x] **P4：** 追赶、重播、重建、重新索引、替换/重组恢复、重置、备份追赶、
      和锚定销售/代币对账。本地过程和受控SQLite故障案例通过；
      硬件断电和公共网络历史记录仍不属于当地证据。
- [x] **P5：** 本地和远程 CI 门、所有权、协作文档、演示和证据。
      远程 CI 证据是特定于提交的。分支机构保护、最终审阅者身份以及
      手动钱包证据仍然由所有者控制检查。

## 数据库 D0–D5

- [x] **D0:** 现有数据库/历史记录检查为只读；非收养环境边界
      记录了。
- [x] **D1：** 一个数据库包、架构、编解码器、托管路径、角色导出、锁和标记。
- [x] **D2：** 本机迁移历史记录、源摘要、运行时检查、注入的 SQL 回滚和
      故障标记恢复已通过。真正的`0000`到`0001`保留数据升级夹具
      涵盖 DB-03 以获取存储库的当前历史记录。
- [x] **D3:** 目录种子、持久链步日志、已知哈希恢复、种子版本冲突以及
      已完成引导程序重用已通过。广播到哈希窗口中真正的进程终止仍然是
      规定的操作系统故障注入间隙。
- [x] **D4：** 备份/恢复、重建/重新索引、重组证据保留、头后恢复追赶、
      对账，一次快照读取，并重置本地通过的部署不匹配检测。
- [x] **D5：** 命令、运行手册、本地全栈演练、重置拒绝矩阵和并行套件
      隔离过去了。 DB-01–DB-54 矩阵保留硬件级别和外部环境
      限制。

- [x] **DOC-P1：** 双语入口点、范围、状态、能力/证据图和导航。
- [x] **DOC-P2：** 架构、依赖规则、数据权威来源、协议、事务和

- [x] **DOC-P3：** 入门、所有权、并行开发和更改方法。
- [x] **DOC-P4：** 测试策略、场景矩阵、演示、运行手册、CI 门和证据记录。
- [x] **DOC-P5：** 链接、名称、命令、生成漂移、双语奇偶校验和虚假证据检查；
      DOC-01–DOC-32 在验收矩阵中进行跟踪。
