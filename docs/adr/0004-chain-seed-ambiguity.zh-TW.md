# ADR 0004：停止不明確的鏈種子結果

[English](0004-chain-seed-ambiguity.md) · [简体中文](0004-chain-seed-ambiguity.zh-CN.md)

## 狀態

已接受。

## 背景

本地引導程式發送非冪等合約部署、鑄造、批准和列出交易。在 RPC 節點接受交易之後但在呼叫者持久記錄其雜湊之前，進程可以停止。再次發送相同的邏輯步驟可以創建另一個合約、鑄造另一個代幣或開啟另一個銷售。 EVM 交易不提供應用程式層級的一次性保證。

## 決定

Bootstrap 使用一個環境擁有的 `seed-journal.json` 並將其綁定到每個邏輯步驟的環境、鏈 ID、發送者帳戶、部署 ID 和不可變意圖摘要。

- 在要求錢包客戶端提交之前堅持`PREPARED`。
- 在等待收據之前，將返回的交易哈希保留為 `SUBMITTED`。
- 成功收貨後才標記`VERIFIED`。
- 重新運行時，請使用已知的提交雜湊並重新驗證經過驗證的收據，而無需再次提交。
- 將擱淺的 `PREPARED` 步驟或結果未知的提交呼叫視為 `UNKNOWN` 並停止。
- 拒絕身分變更、意圖變更和已驗證收據證據的變更。
- 一旦部署清單存在，驗證其鏈身份並執行資料庫追趕，而無需
  發送種子交易。

操作員在調查時保留日誌。返回新的演示狀態使用一次性擁有環境的受保護重置工作流程。

## 後果

常見的重試路徑是確定性的，完成的引導不會覆蓋以後的使用者操作。不明確的廣播可能需要手動證據審查或明確重置。該設計並不要求一次性鏈交易，並且廣播到哈希持久性視窗中的真正進程終止仍然是單獨的故障注入測試。
