# ADR 0006：保持本地演示錢包顯式且僅環回

[English](0006-local-demo-wallet-boundary.md) · [简体中文](0006-local-demo-wallet-boundary.zh-CN.md)

## 背景

在正常操作中，應用程式需要注入 EIP-1193 提供者。無論如何，沒有擴充功能的瀏覽器之前都會收到配置的 Wagmi 注入連接器，因此 UI 會呈現無法完成的連線按鈕。 Playwright 套件始終注入受控提供程序，但不涵蓋該狀態。審核者還需要一種安全的方法來在沒有錢包擴充功能的瀏覽器中操作本地堆疊。

## 決定

- 當 `window.ethereum` 不存在時過濾注入的連接器並呈現不可用狀態。
- 連接控制項旁邊的表面連接器錯誤。
- 僅當 `VITE_MOTORCOVE_DEMO_WALLET=1`、Vite 運行時新增賣家和買家演示連接器
  開發模式，配置的RPC URL為loopback。
- 使用公共Anvil測試位址和解鎖的本地JSON-RPC帳號。不要嵌入私鑰。
- 在其受控的 EIP-1193 提供者上保留故障注入測試並單獨標記該證據
  來自正常的本機演示連接器和手動擴展測試。

## 後果

審核者無需安裝錢包擴充功能即可完成真實的本機交易路徑。生產版本無法啟用演示連接器，且非環回 RPC 被拒絕。手動 MetaMask 行為仍然是一個明確的未經驗證的項目。
