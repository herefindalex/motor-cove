# ADR 0006：保持本地演示钱包显式且仅环回

[English](0006-local-demo-wallet-boundary.md) · [繁體中文](0006-local-demo-wallet-boundary.zh-TW.md)

## 背景

在正常操作中，应用程序需要注入 EIP-1193 提供程序。无论如何，没有扩展的浏览器之前都会收到配置的 Wagmi 注入连接器，因此 UI 会呈现无法完成的连接按钮。 Playwright 套件始终注入受控提供程序，但不涵盖该状态。审核者还需要一种安全的方法来在没有钱包扩展的浏览器中操作本地堆栈。

## 决定

- 当 `window.ethereum` 不存在时过滤注入的连接器并呈现不可用状态。
- 连接控件旁边的表面连接器错误。
- 仅当 `VITE_MOTORCOVE_DEMO_WALLET=1`、Vite 运行时添加卖家和买家演示连接器
  开发模式，配置的RPC URL为loopback。
- 使用公共Anvil测试地址和解锁的本地JSON-RPC账户。不要嵌入私钥。
- 在其受控的 EIP-1193 提供商上保留故障注入测试并单独标记该证据
  来自正常的本地演示连接器和手动扩展测试。

## 后果

审核者无需安装钱包扩展即可完成真实的本地交易路径。生产版本无法启用演示连接器，并且非环回 RPC 被拒绝。手动 MetaMask 行为仍然是一个明确的未经验证的项目。
