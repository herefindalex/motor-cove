# 技術選擇

[English](technology-choices.md) · [简体中文](technology-choices.zh-CN.md)

此頁面回答了檢查的工作區使用哪些工具、為什麼每個工具都有有限的角色，以及安裝中未暗示哪些聲明。確切的版本來自清單、鎖定檔案、Foundry 配置和[工具鏈](toolchain.zh-TW.md) 中的本機工具輸出。

| 技術                                     | 實際角色及進入                             | 為什麼在這裡                             | 邊界與權衡                                           |
| ---------------------------------------- | ------------------------------------------ | ---------------------------------------- | ---------------------------------------------------- |
| React 19 + Vite 8 + TypeScript 5.9       | Web 運行時並在 `apps/web` 下構建           | 具有快速本地構建的小型瀏覽器介面         | 不拥有钱包或服务器状态；当前的浏览器支持没有单独认证 |
| Wagmi 3 + Viem 2                         | 注入連接器和鞋底 TypeScript EVM 用戶端     | 類型為 RPC、ABI 讀/寫、收據和日誌        | 无托管钱包套件、SIWE 或公共网络最终声明              |
| TanStack Query 5                         | API Web 組合中的查詢快取                   | 将服务器快照保留在钱包和表单状态之外     | 新的查詢並不能證明 Indexer 已到達鏈頭                |
| Fastify 5                                | 本地只讀 HTTP API                          | 小顯作文根與健康路由                     | 不是結算引擎，也不是認證服務                         |
| Zod 4+產生的OpenAPI                      | 瀏覽器安全的傳輸資料與部署清單驗證         | 生產者和消費者共享運行時驗證             | 模式有效性并不建立数据新鲜度或链真实性               |
| SQLite 3.53.4 + better-sqlite3 13        | 本地混合權威來源資料庫和同步事務           | 非常適合單主機演示和短原子寫入           | 同一主机WAL和一名作家；没有网络文件系统支持          |
| Drizzle ORM 0.45.2 + Drizzle Kit 0.31.10 | `packages/database` 中的架構和本機遷移工件 | 有序 SQL 歷史記錄和類型化模式來源        | 套件不会取代项目所有权、锁定或验证防护               |
| Solidity 0.8.24 + Foundry/Anvil 1.8.3    | 合約、模糊/不變測試、本地鏈                | 具有受控時間的確定性局部 EVM 循環        | Anvil 不是公網運作的證據                             |
| OpenZeppelin 5.6.1                       | ERC-721、所有權和可重入原語                | 避免自訂令牌/安全原語                    | 整合仍然需要 MotorCove 特定的不變量和測試            |
| Vitest 5 + React 測試庫 16               | 單元和 JSDOM 組件測試                      | 將純規則與呈現的組件狀態檢查分開         | JSDOM 不是注入錢包或佈局引擎的證據                   |
| Playwright 1.63                          | 針對隔離的本機堆疊的瀏覽器 E2E             | 涵蓋可見的交易和恢復流程                 | 自動化 EIP-1193 轉接器不是手動錢包測試               |
| Storybook 10                             | 隔離的 UI 狀態開發                         | 顯示受控組件狀態                         | 賽程僅供說明，非連鎖證據                             |
| pnpm 12.5.1                              | 固定工作區包管理器                         | 確定性工作區和鎖定文件                   | 根腳本仍然是專案指令，而不是 pnpm 內建指令           |
| GitHub Actions                           | 執行遠端 CI 工作流程                       | 鏡像本地文件煙霧、驗證和 E2E 門          | 一次通过的运行并不能证明分支保护或需要审查的设置     |
| TypeScript 架构检查器                    | 導入圖表和負片                             | 在没有框架的情况下强制执行选定的依赖方向 | 检查静态导入；运行时隔离仍然取决于组合               |

建议或排除的工具（例如 Postgres、The Graph、SIWE、Kubernetes、ethers 和 RainbowKit）不属于已实现堆栈的一部分。
