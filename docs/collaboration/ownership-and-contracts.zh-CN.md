# 所有权和合约

[English](ownership-and-contracts.md) · [繁體中文](ownership-and-contracts.zh-TW.md)

此页面标识了提供商表面和所需的消费者审查。角色可由一人担任；分离仍然可以防止隐藏的合约变更。

| 工作流程      | 拥有                               | 发布                                | 受影响的消费者             |
| ------------- | ---------------------------------- | ----------------------------------- | -------------------------- |
| 前端          | 特性、功能、UI 适配器              | UI状态、操作意图、消费者期望        | 质量保证、产品演示         |
| 协议          | Solidity 和部署行为                | ABI、事件、错误、清单语义           | 前端，Indexer，数据库/发布 |
| API           | 查询模块和 HTTP 有线格式           | Zod/OpenAPI，示例，出处             | 前端、质量检查             |
| Indexer       | RPC 摄取、解码器、投影器           | 源范围、投影器版本、检查点/恢复行为 | 数据库，API，操作          |
| 数据库        | 架构、迁移、读取器/写入器/维护导出 | SQL 历史、模式契约、环境/锁定规则   | Indexer、API、工装、QA     |
| 质量保证/工具 | 跨层场景和本地网关                 | 验收证据和故障报告                  | 所有提供者和发布所有者     |

提供商变更需要每个受影响的消费者进行审查。代码所有者可以进行路由审核，但无法证明所有提供商-消费者接受关卡均已通过。尚未提供真实的 GitHub 身份，因此 `.github/CODEOWNERS` 故意不发明所有者。

请参阅[交付工作流程](delivery-workflow.zh-CN.md) 和[更改配方](../onboarding/change-recipes.zh-CN.md)。
