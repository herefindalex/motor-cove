# 變更與發布

[English](change-and-release.md) · [简体中文](change-and-release.zh-CN.md)

此页面定义本地发布证据并将其与远程存储库设置分开。

在合併之前，執行受影響的重點檢查、產生的工件漂移、文件檢查、格式化、lint、類型檢查、架構固定裝置、合約/資料庫/單元/整合/瀏覽器測試和建置。记录实际结果和限制；不要将跳过的手动检查变成通过。

ABI、API、DB、CLI、投影器、部署或場景變更也會更新消費者文件、指令註解、配方、實作狀態和驗證記錄。模式更改狀態資料保存和恢復。 投影器變更狀態重建要求。部署更改狀態身分相容性。

建議的 GitHub 設定包括所需的 CI、已解決的對話、受保護的預設分支、無強制推送和真正的程式碼擁有者審查。每個推送的版本都需要自己的文件smoke、verify和E2E結果；機器證據記錄命名了確切的版本並運行。分支保護、所需審查和 CODEOWNERS 強制執行是單獨的所有者控制設置，成功的工作流程運行並不能證明這些設定。

看 [測試策略](../testing/strategy.zh-TW.md) 和 [交付工作流程](delivery-workflow.zh-TW.md).
