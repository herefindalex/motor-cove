# 所有權和合約

[English](ownership-and-contracts.md) · [简体中文](ownership-and-contracts.zh-CN.md)

此頁面標識了提供者表面和所需的消費者審查。角色可由一人擔任；分離仍可防止隱藏的合約變更。

| 工作流程      | 擁有                               | 發布                                  | 受影響的消費者             |
| ------------- | ---------------------------------- | ------------------------------------- | -------------------------- |
| 前端          | 特性、功能、UI 適配器              | UI狀態、操作意圖、消費者期望          | 品質保證、產品演示         |
| 協定          | Solidity 與部署行為                | ABI、事件、錯誤、清單語意             | 前端，Indexer，資料庫/發布 |
| API           | 查詢模組和 HTTP 有線格式           | Zod/OpenAPI，範例，出處               | 前端、品質檢查             |
| Indexer       | RPC 攝取、解碼器、投影器           | 來源範圍、投影器版本、檢查點/恢復行為 | 資料庫，API，操作          |
| 資料庫        | 架構、遷移、讀取器/寫入器/維護導出 | SQL 歷史、模式契約、環境/鎖定規則     | Indexer、API、工裝、QA     |
| 品質保證/工具 | 跨層場景和本地網關                 | 驗收證據和故障報告                    | 所有提供者和發布所有者     |

提供者變更需要每個受影響的消費者進行審查。代碼擁有者可以進行路由審核，但無法證明所有提供者-消費者接受關卡均已通過。尚未提供真實的 GitHub 身份，因此 `.github/CODEOWNERS` 故意不發明所有者。

請參閱[交付工作流程](delivery-workflow.zh-TW.md) 和[更改配方](../onboarding/change-recipes.zh-TW.md)。
