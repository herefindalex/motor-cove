# 平行開發

[English](parallel-development.md) · [简体中文](parallel-development.zh-CN.md)

本頁解釋了哪些工件可以讓工作獨立進行，哪些門仍然存在硬依賴關係。

前端、API、Indexer、資料庫和協定可以根據經過審核的 ABI、Zod/OpenAPI、部署清單、套件匯出、Drizzle 模式契約和明確測試裝置進行開發。應用程式不得透過來源匯入另一個應用程式來解鎖工作。

ABI 夹具可以在部署之前解锁 UI 状态和解码器单元测试。读卡器接口可以在 Indexer 集成之前解锁 API 演示器。這些模擬不能滿足實際部署、原子攝取或瀏覽器 E2E 閘。

合約和模式變更伴隨著產生的工件、提供者測試、消費者相容性測試、遷移/重建影響、復原路徑和更新的證據元資料。功能分支使用儲存庫命名策略，並且不提交本機資料庫、清單、備份、追蹤或機密。

仅当 API 和 Indexer 消费者合约测试在同一工作树中通过时，数据库提供程序更改才完成。純源提供者測試可以並行進行，但它們不能滿足消費者的要求。
