# 变更与发布

[English](change-and-release.md) · [繁體中文](change-and-release.zh-TW.md)

此页面定义本地发布证据并将其与远程存储库设置分开。

在合并之前，运行受影响的重点检查、生成的工件漂移、文档检查、格式化、lint、类型检查、架构固定装置、合约/数据库/单元/集成/浏览器测试和构建。记录实际结果和限制；不要将跳过的手动检查变成通过。

ABI、API、DB、CLI、投影器、部署或场景更改还会更新消费者文档、命令注释、配方、实施状态和验证记录。模式更改状态数据保存和恢复。 投影器更改状态重建要求。部署更改状态身份兼容性。

推荐的 GitHub 设置包括所需的 CI、已解决的对话、受保护的默认分支、无强制推送和真正的代码所有者审查。每个推送的版本都需要自己的文档smoke、verify和E2E结果；机器证据记录命名了确切的版本并运行。分支保护、所需审查和 CODEOWNERS 强制执行是单独的所有者控制设置，成功的工作流运行并不能证明这些设置。

看 [测试策略](../testing/strategy.zh-CN.md) 和 [交付工作流程](delivery-workflow.zh-CN.md).
